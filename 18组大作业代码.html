def evaluate_model(model, X_train, X_test, y_train, y_test, model_name):
    """
    训练模型并输出评估指标
    """
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    y_proba = model.predict_proba(X_test)[:, 1] if hasattr(model, "predict_proba") else None
    
    acc = accuracy_score(y_test, y_pred)
    prec = precision_score(y_test, y_pred)
    rec = recall_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)
    auc = roc_auc_score(y_test, y_proba) if y_proba is not None else None
    
    print(f"\n{'='*40}")
    print(f"{model_name}")
    print(f"{'='*40}")
    print(f"准确率 (Accuracy):  {acc:.4f}")
    print(f"精确率 (Precision): {prec:.4f}")
    print(f"召回率 (Recall):    {rec:.4f}")
    print(f"F1分数 (F1-Score):  {f1:.4f}")
    if auc:
        print(f"AUC:               {auc:.4f}")
    
    # 混淆矩阵
    cm = confusion_matrix(y_test, y_pred)
    plt.figure(figsize=(4,3))
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
                xticklabels=['良性', '恶性'], yticklabels=['良性', '恶性'])
    plt.title(f'{model_name} 混淆矩阵')
    plt.ylabel('真实标签')
    plt.xlabel('预测标签')
    plt.show()
    
    return {'model': model_name, 'acc': acc, 'prec': prec, 'rec': rec, 'f1': f1, 'auc': auc}

结果分析 一、整体量化指标分析

  1. 准确率 95.61% 测试集共114份样本，仅5例预测出错，模型对乳腺良恶性肿瘤整体识别准确度很高，基础分类效果优秀。但单一准确率无法区分漏诊、误诊两类医疗场景关键错误，需结合其余指标综合判断。
  2. 召回率 97.22%（医疗核心指标） 召回率代表真实恶性肿瘤被检出的比例，本次漏诊率仅2.78%。测试集内72例真实恶性样本仅2例被误判为良性，极大降低恶性肿瘤漏诊、延误治疗的核心医疗风险，完全适配癌症初筛优先避免漏诊的业务需求。
  3. 精确率 95.89% 精确率代表预测为恶性的样本中真实患病的比例，误诊率仅4.11%。所有被模型判定为恶性的73份样本里，仅3例为良性肿块，不会造成大量健康患者承受多余穿刺、复检与心理负担，误诊成本可控。
  4. F1分数 0.9655 作为精确率与召回率的调和均值，数值接近0.97，说明模型不存在极端偏向某一类样本的问题，在减少漏诊和控制误诊之间达到均衡，分类逻辑稳定。
  5. AUC 0.9788 AUC接近0.98属于极佳判别水平，代表模型区分良恶性样本的底层能力很强，不受分类阈值影响，泛化鲁棒性优秀；同时印证前期标准化操作有效解决了KNN距离计算受特征量纲干扰的问题。

二、混淆矩阵错误样本细分分析 混淆矩阵样本分布：良性真实样本42例（39例判断正确、3例假阳性误诊），恶性真实样本72例（70例判断正确、2例假阴性漏诊）。

  1. 3例假阳性（FP） 少量良性肿块被判定为恶性，原因是该部分良性细胞特征分布与恶性样本高度重叠，KNN依靠局部近邻投票产生偏差。仅占总测试样本2.6%，对整体结果影响微弱。
  2. 2例假阴性（FN） 存在2例高风险漏诊样本，是模型唯一临床隐患。这类恶性样本特征贴近多数良性样本，周边近邻以良性为主导致投票出错，但漏诊样本数量极少，风险整体可控。
  3. 正确样本占比极高 39份良性、70份恶性样本识别准确，绝大多数病例可被精准区分，能够作为有效的辅助筛查工具。

三、模型表现优劣总结 优势

  1. 医疗核心指标表现突出，漏诊概率极低，贴合肿瘤筛查的业务优先级；
  2. 整体分类精度、二分类判别能力均达到优秀水平，少量错误集中在特征边界重叠样本；
  3. 适配当前数据集规模，标准化流程解决KNN固有量纲缺陷，无严重拟合问题。

现存缺陷

  1. 对特征分布边缘的异常、重叠样本识别能力弱，存在少量漏诊、误诊；
  2. KNN惰性学习模式下，样本量扩充后预测速度会明显下降；
  3. 未完成超参数寻优，当前k=5并非理论最优值，仍有性能提升空间。

四、业务落地结论 该k=5标准化KNN模型可用于乳腺肿瘤良恶性辅助筛查：整体识别精度高，核心的恶性漏诊风险极低，误诊数量少，综合指标表现优异。仅存在极少量边界样本错分，通过调整K近邻数量、加权投票、特征降维等手段可进一步降低错误样本，具备临床辅助诊断使用价值。

  1. 随机森林AUC（0.9939）远高于KNN（0.9788）**：随机森林集成多棵决策树，抗噪声、抗边缘异常样本能力更强，底层区分良恶性的泛化能力更优秀；KNN为惰性学习，易受边界重叠样本干扰，判别稳定性略差。

    • KNN：预测需遍历全部训练集计算距离，数据量扩大后推理速度会明显下降；必须依赖标准化，流程多一步预处理；
    • 随机森林：训练完成后推理速度快，原生不受特征量纲影响，即使不标准化也能稳定输出结果，工程落地更便捷；可输出特征重要性，辅助医生定位关键检测指标，可解释性优于KNN。

  2. AUC仅0.9163，四类模型最低，单棵浅层树拟合能力有限，无法捕捉复杂非线性特征关联，极易受局部样本分布影响；
  3. 唯一优势：精确率0.9565略高于KNN与随机森林，误诊控制尚可，但极低召回率完全抵消该优势；

四、医疗业务场景选型结论

  1. 首选模型：SVM(RBF核) 综合精度、漏诊/误诊控制、判别鲁棒性全部最优，标准化流程简单，样本量适中时推理速度快，是乳腺癌辅助诊断的最优选择。
  2. 备选模型：随机森林 综合精度略低于SVM，但无需依赖标准化、推理高效、可输出特征重要性辅助医学分析，适合需要模型可解释性、大批量样本推理的场景。
  3. 次选模型：KNN(k=5) 基础精度合格，但存在推理慢、依赖标准化、易受边界样本干扰的短板，仅适合小样本离线分析，不适合线上实时筛查。
  4. 不推荐单独使用：浅层单决策树 漏诊风险过高，泛化能力薄弱，仅可作为教学演示、集成学习的基础组件，不能单独落地用于肿瘤筛查。

五、实验优化方向

  1. 对SVM、KNN执行网格搜索超参数寻优，遍历核函数、k值、惩罚系数，进一步压低漏诊率；
  2. 对决策树取消深度限制、采用剪枝操作，或提升集成树规模，缩小与SVM的性能差距；
  3. 结合临床风险偏好调优分类阈值：若优先杜绝漏诊，可下调恶性判定阈值，牺牲少量精确率换取更高召回率；
  4. 特征筛选降维，剔除冗余检测指标，缓解KNN维度灾难，同步提升全部模型训练与推理效率。
